Pseudo-random number generation is the way in which most random numbers are generated by computers, except for some specific cases, including numbers used in cryptography, These PRNGs as I will call them throughout this work by generating numbers using an algorithm and a seed value. Every time you run a given PRNG algorithm with the same seed, you will always get the same output in the same order. If you change the seed, you will get a different order. One example where PRNGs are used is in Minecraft world generation. This is why you can give someone your world seed, and they will generate the same world, as long as they are using the same Minecraft version. In this example, the Minecraft version is the algorithm, and the world seed is the seed.
